I'm trying an original, label-free collaborator-style cursor on desktop. It follows the mouse, responds to links and clicks, and matches both themes. Touch devices, reduced motion, and text inputs use the normal cursor. I can turn the experiment off with `cursorEnabled` in `components/ui/portfolio.tsx`. This is my own implementation, inspired by the [React Bits Pro User Cursor demo](https://pro.reactbits.dev/docs/components/user-cursor).
